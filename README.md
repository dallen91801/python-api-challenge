#Project Overview

This Weather Dashboard project provides users with real-time weather updates for cities across the globe. The project utilizes weather data to display current conditions and forecasts, enhancing the user experience with interactive maps that show the nearest hotels to the chosen city.

#Resources and Acknowledgments

APIs Used:
Geoapify Places API: This project uses the Geoapify Places API to fetch hotel information based on city coordinates. More about Geoapify can be found at Geoapify Documentation.

OpenWeatherMap API: I use the OpenWeatherMap API to access real-time weather data for various locations around the globe.
